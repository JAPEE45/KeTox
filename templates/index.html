About KeTox &
Methodology

KeTox is a research prototype that predicts whether a small-molecule compound is likely to inhibit CYP3A4 — the primary hepatic metabolic enzyme — using Ketoconazole as a structural and pharmacological reference standard. The system combines classical machine learning (Random Forest) with a graph neural network (GCN), enriched by PBPK-derived liver concentration modelling and three complementary XAI methods.

Validation Framework

Three held-out test sets designed to probe different generalisation challenges, inspired by the Ketoconazole reference structure.

High Overlap

Sibling Set

Structurally similar compounds to Ketoconazole (Tanimoto ≥ 0.4). Tests whether the model correctly flags structurally related — but potentially novel — CYP3A4 inhibitors. The hardest set to get right.

Tanimoto ≥ 0.4 to Ketoconazole

Diverse Scaffolds

Stranger Set

Structurally dissimilar inhibitors (Tanimoto < 0.4). Tests whether the model generalises beyond the Ketoconazole scaffold to other chemotypes that still inhibit CYP3A4.

Tanimoto < 0.4 to Ketoconazole

Specificity Control

Safe Set

Confirmed non-inhibitors from the PubChem assays. Tests specificity — the model should not flag these as toxic. High false-positive rates here indicate over-sensitivity.

Confirmed non-inhibitors · Active = False

Explainability Methods

Three complementary XAI methods provide both global and local interpretations of model behaviour.

Global & Local Attribution

SHAP

SHapley Additive exPlanations assigns each feature a contribution score based on game theory. Used on the Random Forest model to explain global feature importance and individual predictions.

TreeExplainer · Additive feature importances

Rule-Based Local Surrogate

LIME

Local Interpretable Model-Agnostic Explanations builds a simpler interpretable model around each input to explain which molecular rules pushed the prediction toward toxic or safe.

Linear Local Surrogate · Perturbation testing

Graph Neural Attention

GraphGrad-CAM

Graph Gradient-weighted Class Activation Mapping highlights specific atoms and bonds within the 2D molecular structure that the GCN focused on, providing a visual structural explanation.

GCN Class Activation · Atom-level gradient map
